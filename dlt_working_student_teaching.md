# dlt Working Student Teaching

We suggest aiming for a max 4-6h effort, keeping things simple, and showcasing your best.

## Step 1: Describe Your Use Case

Describe how you would use dlt in a previous situation. If you do not have a previous case, imagine where dlt would be helpful and describe it.

## Step 2: Build a dlt Pipeline

What we look for:

- **Code quality** - is it clean and readable?
- **dlt usage** - are you declaring sources and resources? Are you using merge or incremental load?
- **Use case** - Does the use case for the pipeline make sense, or is it purely theoretical?

## Step 3: Design a Workshop

Imagine you want to create a workshop to teach people how to use dlt. For example, you have an audience of 60 people and 1 hour. Consider:

- Will this be an offline event or online? Why?
- Describe content sections or create paragraphs/bullets
- Which format would you choose? Presentations, live demos, colabs, all together, something else?
- Which example code would you choose to demonstrate?
- How would you keep your audience's attention?
